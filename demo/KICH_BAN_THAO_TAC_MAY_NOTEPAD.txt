PHẦN 3: TỐI ƯU HÓA HIỆU NĂNG VÀ MODULE AI 2 (PERFORMANCE DEMO)
################################################################################

--- [BƯỚC 3.1: Đảm bảo quyền Owner & Xóa index cũ để đo trước khi tối ưu] ---
👉 Copy dán vào SQL EDITOR:

RESET ROLE;
DROP INDEX IF EXISTS billing.idx_invoice_total_amount;


--- [BƯỚC 3.2: Đo khi CHƯA có Index -> Kết quả: Seq Scan (Quét toàn bảng)] ---
👉 Copy dán vào SQL EDITOR (Chỉ chuột vào dòng 'Seq Scan on invoice'):

EXPLAIN (ANALYZE, BUFFERS)
SELECT invoice_id, customer_id, cashier_id, total_amount, status 
FROM billing.invoice 
WHERE total_amount = 630000;


--- [BƯỚC 3.3: Tạo B-Tree Index và đo lại -> Kết quả: Index Scan (Nhảy thẳng)] ---
👉 Copy dán vào SQL EDITOR (Chỉ chuột vào dòng 'Index Scan using idx_invoice_total_amount'):

CREATE INDEX idx_invoice_total_amount ON billing.invoice (total_amount);

SET enable_seqscan = off;

EXPLAIN (ANALYZE, BUFFERS)
SELECT invoice_id, customer_id, cashier_id, total_amount, status 
FROM billing.invoice 
WHERE total_amount = 630000;

SET enable_seqscan = on;


--- [BƯỚC 3.4: Module AI 2 - AI tự động quét Catalog và khuyến nghị Index] ---
👉 Copy dán vào SQL EDITOR:

SELECT recommendation_id, table_name, column_list, reason, suggested_sql 
FROM ai.fn_recommend_indexes() 
LIMIT 3;

PHẦN 4: ĐIỂM NHẤN TÍCH HỢP & 3 MODULE AI THỜI GIAN THỰC (AI HIGHLIGHTS)
################################################################################

--- [BƯỚC 4.1: Bóc tách dữ liệu bán cấu trúc NoSQL từ cột JSONB (->> và @>)] ---
👉 Copy dán vào SQL EDITOR:

SELECT 
    computer_code, 
    computer_name,
    specs ->> 'cpu'     AS cpu_model,
    specs ->> 'gpu'     AS graphics_card,
    specs ->> 'ram'     AS memory_size
FROM core.computer
WHERE specs @> '{"gpu": "RTX 4070"}'::jsonb;


--- [BƯỚC 4.2: AI Cảnh báo rủi ro An ninh thời gian thực (LISTEN / NOTIFY)] ---
👉 Bước A (Cửa sổ TERMINAL bên Phải): Chạy lệnh lắng nghe tín hiệu:
python python/listen_ai_alerts.py

👉 Bước B (Cửa sổ SQL EDITOR bên Trái): Chạy lệnh nạp tiền lớn bất thường (10 triệu):

👉 Bước C: Nhìn sang cửa sổ Terminal -> Nổ CẢNH BÁO ĐỎ thời gian thực!
(Sau đó bấm tổ hợp phím Ctrl + C trên Terminal để dừng tiến trình).


--- [BƯỚC 4.3: Module AI 4 - Thuật toán thống kê Z-Score phát hiện ngoại lai] ---
👉 Copy dán vào SQL EDITOR:
